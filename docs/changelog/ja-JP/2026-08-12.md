# 2026.08.12 アップデート

1. 同じプロバイダーへの接続を複数まとめて保持できるようになりました。中継業者などから使えるモデルの異なる API キーを複数受け取っている場合、これまでは後から保存したものが前のものを無言で上書きしていました——保存できたように見えて、実際に生きているのは最後の1組だけ。今は2つ目以降の接続に短い「接続スラッグ」を付けると、それがモデル選択で表示される id の一部になり（例：`custom_openai_compatible__relay-b`）、各接続カードにも自分の id が表示されます。スラッグを空のままにすれば名前は従来どおりで、既存の設定には一切影響しません。チャット・画像・動画で利用でき、音声・埋め込み・検索は引き続き1つずつの接続です。
2. キャラクターが「あとで話すね」と約束したら、ちゃんと戻ってくるようになりました。以前はこうした約束が彼女自身の自発メッセージのクールダウンに阻まれ、その時間が何もないまま過ぎてしまうことがありました。今は約束ごとに「戻る時刻」を持ち、クールダウン中でも約束は果たされます。
3. 返信の言語がより安定し、たまに別の言語で返ってしまう問題を修正しました。また、ツール（検索・画像認識・画像生成など）を差し出すかどうかの判断を、まとめてではなくツールごとに行うようにしました。
