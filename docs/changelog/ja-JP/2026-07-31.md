# 2026.07.31 アップデート

1. 同席モードに許可が要らなくなりました：「いる」と言えば、そこにいられます。切り替えは一瞬で完了し、「あなたがそこにいるのは妥当か」をシステムが審査してブロックや警告を出すことはもうありません。あなたの居場所は、あなたが決めるものです。
2. キャラクターがあなたの登場に本当の反応を返します：彼女は自分の予定に沿って演じます——外で用事の最中に現れれば驚き、家にいれば日常の温度で迎える。ひとりでいたい時間には、「ちょっと待ってて」とドア越しに話すなど、役の中で自分から線を引きます。システムが彼女の代わりに断るのではありません。また、あなたの行動や来た経緯を勝手に創作することもありません。
3. キャラクターは「いま自分が何をしているか」を分かっています：同じ部屋にいてもスマホ越しでも、彼女はいまの状況——何の途中か、いま何時か——を踏まえて話すので、場面の感覚と時間の感覚がズレません。
4. ストーリーの章が同じ旋律を繰り返さなくなりました：新しい章を計画するとき、これまでの章を振り返って「衣替えしただけの同じ筋」を避け、同梱の物語の種から新しい題材を取り込みます。展開が平坦なまま続いたときは、会話の外から新しい出来事を意図的に持ち込んで、よどんだ水をかき混ぜます。
