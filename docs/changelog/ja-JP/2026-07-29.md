# 2026.07.29 アップデート

1. 約束がちゃんと「過去」になるようになりました：キャラクターと交わした約束は、時間が過ぎれば自然に区切りがつきます。とっくに流れた誘いを何度も持ち出すことはなくなり、翌日になってからの「行くよ」もきちんと約束として扱われます。実現しなかった約束は「あの日は行けなかったね」と正直に締めくくられ、行ったことにされたり、いつまでも引きずられたりしません。
2. 一緒にやっていないことが「一緒にやった」思い出になりません：あなたが実際に参加した活動だけが、思い出やフィードにあなたを含めて記録されます。身に覚えのない「二人の思い出」が増えることはもうありません。
3. キャラクターの記憶に本当の日付が入ります：これまで記憶に書かれた「明日」「来週」は時間とともにズレていました（数週間後もまだ「明日が楽しみ」と言うなど）。今は書き込む時点で具体的な日付に変換されるため、時間の感覚が狂いません。
4. 長期的な目標は定期的に整理されます：達成したものは閉じ、期限切れは手放し、似たものは統合。永遠に残り続ける目標リストの積み上がりがなくなり、会話には関連の深いものだけが持ち込まれます。
5. スケジュールが実際の天気と食い違わなくなりました：先の日の予定を立てるとき天気を勝手に想像しなくなり、当日の天気が予定と明らかに矛盾する場合（急な雨など）は、矛盾する部分だけが自動で調整されます。すでに起きたことや、あなたと約束した部分は変更されません。
6. 日常と物語のネタを大幅拡充：同梱の生活の小さな出来事や物語の種を二百件以上追加（日本や欧米の地域色を含む）し、二か月間は繰り返さないことを保証。予定作りも、同じ種類の活動を連日並べるのを避け、続きものの活動には新しい進展を持たせるようになりました。日常が「再放送」にならなくなります。
7. 謎の繰り返しがなくなりました：同じ自発メッセージが複数のチャットチャンネルに同時に届いたとき、キャラクターがそれを新しい内容と勘違いしてもう一度話すことはなくなりました。
8. 突然ログアウトされなくなりました：使い続けている間はセッションが自動的に延長され、利用中にタイマーで追い出されることがありません。
9. 安定性とセキュリティの修正：特定条件でスケジューラーが空回りし続ける再試行ループ、起動時にサイトのカスタム設定がまれに読み込まれない問題を修正し、既知の脆弱性を含む依存関係をいくつか更新しました。
