# 2026.08.17 アップデート

1. 分岐ドラマに「あなた」の立ち位置が加わりました。開始時に自分が物語のどこにいるかを選べます——主演（物語はあなたを中心に回り、ナレーションはあなたに語りかける）、その場にいる脇役、または純粋な観客——さらに「劇中で誰を演じるか」を一言添えることもできます（例：「彼女と長年音信不通だった兄」）。ナレーションと物語はその立ち位置に合わせて書かれます。ルートを最後まで歩いた後も行き止まりではありません：別の分岐でもう一度遊ぶ、そのルートを脚本に仕立てて続きを育てる、全文の記録を書き出して手元に残す、という出口が用意されています。
2. 分岐ドラマのシーン画像は描き直せるようになりました。生成に失敗した一枚を補ったり、気に入らない一枚を差し替えたり——変わるのは画像だけで、物語はそのままです。進行度の表示も正確になりました。
3. 「あなたのプロフィール」を新設：キャラクターごとに「自分が誰か」を伝えられます——身分や背景、二人だけの秘密の設定まで。以降、ふだんの会話でも、彼女から届くメッセージでも、約束の時間でも、物語の幕開けでも、コメント返信でも、彼女があなたに話しかけるときはいつでもそれを覚えています。チャット画面の上からいつでも編集できます。従来の個人設定「今の状態」は役目を終え、この機能に置き換わりました。
4. 同席モードで、彼女に先に話してもらえるようになりました。入力欄に新しいボタンが増え、どう切り出せばいいか分からない時や、この瞬間を彼女に任せたい時に押すだけ。今の場面を補足してもいいし（例：「ドアを開けて入ってくる」）、空欄のままでも構いません。
5. Webアプリが古いバージョンのまま止まらなくなりました。これまでは更新後も、開きっぱなしのタブが古い画面を使い続け、手動でサイトデータを消すまで切り替わりませんでした。今は新しいバージョンを自動で検知して更新されます。
