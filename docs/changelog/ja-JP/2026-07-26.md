# 2026.07.26 アップデート

1. 一つの環境を複数人で使っている場合、天気と祝日がようやくそれぞれ別々になりました：これまでは全員のキャラクターがサイト管理者の設定した所在地に合わせて天気を感じ、連休の話をしていました。今後は各キャラクターが「自分の持ち主」の所在地を見ます。二人のプレイヤーのキャラクターが出会う場面では、片方の所在地を唯一の基準とします（会話の言語や時刻をすでに決めている側と同じ）。同じ場面に二つの天気が現れることはありません。所在地が未設定のアカウントは従来どおり環境の既定値を使うため、おひとりでのセルフホストでは体感は変わりません。
2. ニュースソースに「内容の地域」を設定できるようになりました：管理画面で RSS ソースに地域を付けると、その地域に住むプレイヤーだけがその話題を受け取ります。地域を付けないソースはグローバル扱いで全員に届きます。国を設定していないプレイヤーには一切フィルタがかかりません。国境を越えて読まれるメディアはグローバルのままにしておくのがおすすめです。
3. 同じキャラクターが同時に複数の場所から動かされても、同じ処理を二度行わなくなりました：物語の進行、デイリーストーリー、記憶の整理などが、ごく短い間に二度起動することがありました（ウェブとメッセージアプリから同時に送った場合など）。今後は実行されるのは一つだけで、もう一方は止められて後ほど再試行されます。同じキャラクターが二本のメインストーリーを同時に進めてしまうこともなくなりました。
4. 外部メッセージアプリが同じメッセージを再送しても、キャラクターが二度返信しなくなりました：受信記録をデータベースに保存するようにしたため、再試行や再送も「これは受け取り済み」と判断できます。キャラクターがちょうど別の返信中だった場合は、メッセージを飲み込まずに、少し後で再送するようプラットフォームに依頼します。
