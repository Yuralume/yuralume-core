# 2026.07.22 アップデート

1. キャラクターのバックグラウンド生活が「ゆっくりする」ことを覚えました：従来のアイドル凍結に加えて、よりやさしい選択肢を追加——数日間キャラクターとやり取りがないと、自発メッセージ・フィード投稿・キャラ同士の交流・夢などのバックグラウンド活動が自動的にペースを落とし、不在の間の費用を抑えます。メッセージを送れば数分ほどで元の活発さに戻ります。「アイドル」の判定はあなた自身の最後のやり取りだけを見ます——キャラクターが勝手に行う活動はカウントされません。
2. API 費用をこっそり消費する問題を修正：物語のシーン進行がまれに詰まったとき、これまでは（画面には何も見えないまま）モデル呼び出しを延々と再試行していました。再試行に上限と徐々に延びる間隔を設け、無限に費用を燃やすことはなくなりました。
3. 音声サービスを設定していない場合、チャットメッセージに音声再生ボタンを表示しないようにしました——押しても何も鳴らない戸惑いを解消。音声を設定すればボタンは従来どおり表示されます。
