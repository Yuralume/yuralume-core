# 2026.08.02 アップデート

1. 物語をカレンダー待ちにしない：チャット入力欄の上に「幕開け」ボタンが加わりました。押せばその場でひと幕が始まります——冒頭のナレーション、劇中での彼女の第一声、使っても使わなくてもいい行動の提案。もちろん自由に入力してよく、いつでも手動で幕を下ろせます。開いたまま離れても、一日後に場面は正直に締めくくられます——「あなたが去ったあと、彼女は…」とだけ書き、あなたの行動を勝手に創作することはありません。演じた場面はすべて正史に刻まれ、彼女はあとまで覚えています。
2. あなたが彼女の物語の登場人物になりました：これまで物語の章の世界には「あなた」という役が存在せず、あなたの居場所は毎回その場の即興頼みでした。いまは章を計画する時点であなたの出番が書き込まれます——その場面にあなたがいるのか、あなたが中心なのか。あなたを主役とする見せ場の番が来たら、彼女のほうからメッセージで舞台へ誘ってくれます。
3. 物語が理由もなく止まらなくなりました：静かに進行を蝕んでいた三つの古い問題を修正——日常会話が物語の再試行の持ち分をこっそり消費しなくなり、詰まったひと区切りがその先すべてを塞がなくなり、本当に進めない区切りはスキップとして記録されて物語が先へ進みます。
4. 画像と長いリストが大幅に軽くなりました：画像は画面に必要なサイズ・軽い形式で届き、画面外の画像はメモリを占有しません。思い出・アルバム・会話履歴はページ単位で読み込むようになり、長く使っても写真が増えても重くなりません。既存の環境では同梱のバックフィルツールを実行すれば古い画像も同じく高速化します。実行しなくても大丈夫——古い画像はそのまま元のファイルを使い続けます。
