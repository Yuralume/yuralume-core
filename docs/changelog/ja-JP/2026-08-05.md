# 2026.08.05 アップデート

1. 公式キャラクターが一気に7人追加（合計10人に）：それぞれに練り込まれた人物像、自分の生活スケジュール、専用の画風があります。公式ギャラリーを眺めて、気に入った子を迎えてください。

3. 公式カードは3言語を内蔵：これまで言語を切り替えるとその場で翻訳が走り、あなたのモデル枠と待ち時間を使っていました。今は中・英・日の内容があらかじめ入っていて、インターフェースの言語でそのまま表示されます——翻訳ボタンも、トークン消費もありません。
4. 番外ストーリーの表紙と回想録の背景画像をサイズ最適化：ページ表示が速く、通信量も軽くなりました。
