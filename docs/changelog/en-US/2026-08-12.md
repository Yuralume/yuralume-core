# Update 2026.08.12

1. You can now keep several connections to the same provider at once. If your relay or proxy vendor issued multiple API keys that each serve a different set of models, the one you saved later used to silently overwrite the earlier one — the settings looked saved, but only the last one was actually live. Now every connection after the first takes a short *connection slug*, which becomes part of the id you pick in the model selector (for example `custom_openai_compatible__relay-b`), and each connection card shows its own id. Leave the slug blank and the name stays exactly as it was, so existing setups are untouched. Chat models, image and video all support this; voice, embedding and search still mount one backend at a time.
2. When a character says "I'll tell you later", she actually comes back for it. Those promises used to get blocked by her own proactive-message cooldown, so the moment came and went without a word. A promise now carries its own revisit time, and she keeps it even if the cooldown is still running.
3. Reply language is steadier — the occasional answer that slipped into another language is fixed — and whether a tool (search, image reading, image generation…) is worth putting in front of her is now decided per tool, instead of handing her the whole set at once.
