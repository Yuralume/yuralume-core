# Update 2026.07.22

1. Characters' background life now knows how to slow down: alongside the existing idle freeze, there's a gentler option — after several days without interacting with a character, background activity (proactive messages, feed posts, character-to-character visits, dreams) automatically eases its pace, spending less while you're away. Send a message and the normal tempo returns within a few minutes. "Idle" is judged only by your last real interaction — a character's own background activity doesn't count.
2. Fixed an issue that could quietly burn API cost: when a story scene occasionally got stuck advancing, the system used to retry the model call over and over (with nothing visible to you); retries now have a cap and gradually longer intervals, so nothing burns money indefinitely.
3. When no voice service is configured, chat messages no longer show the voice playback button — no more pressing it and hearing nothing. Once voice is set up, the button appears as usual.
