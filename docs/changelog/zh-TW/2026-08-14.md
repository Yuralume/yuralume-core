# 2026.08.14 更新版本

1. 起幕的開場更有故事感了：以前開場常常只有短短幾句舞台指示，還會冒出沒解釋過的專有名詞，讓人不知道自己身在哪、發生了什麼。現在開場是好幾段的小說式敘事——有畫面、有動作、有人聲，故事裡的名詞第一次出現就會在情節裡交代清楚，最後把鏡頭收回你身上，接著她對你說第一句話。
2. 起幕後的快速回覆選項，說回你自己的話了：之前這些選項偶爾會給出「她的台詞」而不是你要說的話，點下去等於替她發言。修正後選項一律是你的第一人稱。另外，劇本挑選視窗在手機上（瀏海螢幕、網址列彈出時）按鈕被裁掉的問題也一併修了。
3. 答應你的事，現在會真的去做：角色說「晚點幫你查」「回頭傳照片給你」，時間到她會實際去查資料、去把照片準備好，再帶著結果回來找你——而不是永遠停在「我還在弄」。如果沒成功（查不到、照片出不來），她也會誠實告訴你晚點再補，不會憑空編一個結果敷衍過去。
4. 安全性更新：更新了部署映像與加密相關的底層元件。
