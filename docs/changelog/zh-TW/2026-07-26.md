# 2026.07.26 更新版本

1. 一個部署上有多位使用者時，天氣與節慶終於各過各的：過去所有人的角色都跟著站長填的所在地感受天氣、談連假；現在每個角色都看自己主人設定的所在地。兩位玩家的角色碰面時，該場景會以其中一方的所在地為準（和原本決定對話語言、時間的那一方相同），避免同一場景出現兩種天氣。沒有填所在地的帳號維持沿用部署預設，單人自架的體感不變。
2. 新聞來源可以標「內容地區」：站長在管理後台為每個 RSS 來源標上地區後，只有住在該地區的玩家會收到那個來源的話題；不標地區的來源視為全球，所有人都收得到。玩家沒有填所在國家時完全不過濾，跨國閱讀的媒體也建議維持全球。
3. 同一個角色被多個地方同時觸發時，不會再重複做同一件事：劇情推進、每日故事、記憶整理等原本可能在極短時間內被啟動兩次（例如你在網頁和通訊軟體同時傳訊息）；現在同一時間只有一個會真的執行，另一個會被擋下並稍後再試，也不會再出現同一角色同時跑兩條主線的狀況。
4. 外部通訊軟體重送同一則訊息時，角色不會再回覆兩次：訊息的收訖紀錄改為寫入資料庫，重試或補送都認得出「這則我收過了」；若角色當下正在回覆別的訊息，系統會請對方稍後重送，而不是把訊息吞掉。
