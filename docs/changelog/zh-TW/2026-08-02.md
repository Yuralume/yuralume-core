# 2026.08.02 更新版本

1. 想看劇情，不用再等日曆：聊天輸入框上方多了「起幕」按鈕。按下去就開一場戲——開場敘述、她在戲裡的第一句話、兩三個可用可不用的行動建議，你隨時可以照打自己的字、隨時手動落幕。開場走掉不管，一天後戲會自己誠實收尾——只寫「你離開之後她……」，絕不虛構你做過什麼。演過的每一場都會寫進正史，她之後都記得。
2. 你正式住進她的故事裡：過去劇情章節的世界裡其實沒有「你」這個角色，你的位置全靠臨場即興。現在規劃劇情時就會安排你的戲份——這一段你在不在場、是不是主角；輪到以你為中心的重頭戲時，她還會主動傳訊邀你進場對戲。
3. 劇情不再莫名停住：修掉三個沉默的老問題——日常聊天不再悄悄消耗劇情的重試額度、一個卡住的段落不再堵住後面所有段落、真的走不下去的段落會被標記略過，讓故事繼續前進。
4. 圖片與長清單大提速：圖片改依畫面需要的大小與輕量格式傳輸、不在畫面上的圖不再佔用記憶體；回憶、相簿與對話紀錄改為分頁載入——開得久、圖再多也不會越用越卡。既有站台可執行隨附的回填工具讓舊圖片一樣加速；不執行也沒關係，舊圖會自動沿用原檔。
