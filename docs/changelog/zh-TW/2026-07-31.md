# 2026.07.31 更新版本

1. 同場模式不再需要「通行許可」：你說你在場，就在場。切換一瞬完成，系統不會再審核「你出現在這裡合不合理」而擋下或警告你——你人在哪裡，由你決定。
2. 角色會對你的出現做出真實反應：她照著自己的行程演——你在她外出辦事時突然現身，她會嚇一跳；她在家時，就是日常的溫度。想獨處的時刻，她會在戲裡請你稍等、隔著門說話，由她自己劃界，而不是系統替她拒絕你。她也不會憑空編造你做了什麼、怎麼來的。
3. 角色隨時知道自己「現在正在做什麼」：不論同場相處還是手機訊息，她都帶著此刻的狀態聊天——正在忙什麼、現在幾點——場景感與時間感不再脫節。
4. 劇情章節不再舊調重彈：規劃新章節時會先回顧先前的章節，避免同一套劇情換個外皮再來一次，並從隨附的劇情素材池抽取新題材；平淡太久時，還會刻意從對話之外帶進一件新鮮事，把死水攪活。
