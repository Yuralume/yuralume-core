# 2026.08.17 更新版本

1. 分歧劇場補上了「你」的位置：開戲時可以選你在戲裡是誰——主演（故事繞著你轉、旁白直接對你說話）、在場配角，或純旁觀者——還能補一句你在劇中演誰（例如「我演她失聯多年的哥哥」），旁白和劇情會照著你的位置寫。走完一條路之後也不再是死路：可以換條路再走一次、把這條路改編成正式劇本繼續發展下去，或匯出整段逐字稿留作紀念。
2. 分歧劇場的場景圖現在可以重繪：沒生出來的可以補、不滿意的可以換一張——只換圖，劇情本身不會變。另外推進的進度顯示也更準了。
3. 新增「你的人設」：可以對每位角色分別自述你是誰——身分、背景，甚至只有你們倆才知道的祕密設定。之後不管是平常聊天、她主動傳訊、回來赴約、故事開場還是動態留言回覆，她對你說話時都會記得這件事。聊天頁上方隨時可以點開修改；原本個人設定裡的「我現在的狀態」功成身退，由這個功能取代。
4. 同場模式可以讓她先開口了：輸入列多了一顆「讓她先開口」的按鈕，不知道怎麼起頭、或想把這一刻交給她發揮時，按一下就好；也可以補充當下的場景（例如「我推開門進來」），或什麼都不填。
5. 網頁版更新不再卡在舊版：以前更新上線後，一直開著的分頁會繼續用舊版介面，要手動清除網站資料才會換新；現在會自動偵測到新版本並完成更新。
