# 2026.07.22 更新版本

1. 角色的背景生活現在懂得「放慢」：在原本的閒置凍結之外，新增更溫和的選項——當你好幾天沒跟角色互動，主動訊息、動態、角色互訪、夢境等背景活動會自動放慢節奏，離開期間少花費用；你一回來傳訊息，大約幾分鐘內就恢復原本的活躍度。判斷「閒置」只看你上次真正的互動，角色自己在背景的活動不算數。
2. 修掉一個會默默消耗 API 費用的問題：故事場景推進偶發卡住時，之前系統會不停重試呼叫模型（而且你完全看不到）；現在重試有上限、間隔會逐步拉長，不再無限燒錢。
3. 沒有設定語音服務時，聊天訊息上不再顯示語音播放鈕，避免按了卻沒聲音的困惑；設定好語音後按鈕會照常出現。
