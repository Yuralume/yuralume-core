# 2026.08.11 更新版本

1. 新增完整角色備份：可以把養起來的角色——人設、記憶、對話、行程、相簿——整隻打包成一個加密備份檔，用一次性密碼保護。留著離線收藏，或搬到另一個安裝重新迎回來都可以；就算是還沒有任何角色的全新環境，也能直接用備份檔還原。密碼請務必自己收好：沒有密碼，任何人（包括我們）都打不開這個檔案。
2. 角色分享過的新聞，現在追問得下去了：以前她主動跟你聊一則新聞之後，你再問細節，她會什麼都想不起來；現在最近幾天提過的新聞會連同原文出處留在她手邊，追問時她答得上來。
3. 聊天視窗往回翻舊訊息時，會出現一個「跳回最新」的浮動箭頭，按一下直接回到最新訊息；也修正了剛開頁或切換角色時，畫面有時停在半路、沒捲到底的問題。
4. 通訊平台串接的憑證填錯時（例如貼錯 bot token），帳號卡片會直接顯示問題出在哪、該怎麼修，修好後自動恢復連線；後台也不再為此每幾秒重試一次。
