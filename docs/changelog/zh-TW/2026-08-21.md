# 2026.08.21 更新版本

1. 全站看圖體驗統一：點開圖片不再跳到新分頁，改成站內浮窗直接放大——可以左右切換、手勢滑動、雙指縮放，Esc、點背景或手機返回鍵都能關閉，也保留「開原圖」可以看原始檔或另存。聊天圖片、相簿、動態貼文都換上了；舞台縮圖、生成候選圖、角色卡卡面這三處本來完全點不開大圖，現在也都能放大看了。
2. 分歧劇場的完成度變準了：以前的進度比值算法有結構性問題，怎麼走都停在差不多的數字；現在改成以整棵故事樹計算的真實百分比，走得越多就漲得越多。同時新增「分歧圖」——用點和線畫出你走過的路與還沒走的岔路（不劇透內容），結局頁和圖集面板都看得到；劇場入口也改成環形進度呈現。
3. 分歧劇場新增場景圖集：走到的場景會自動收集進圖集，還沒走到的顯示鎖定格、不透露內容；看完結局可以直接從結局畫面打開圖集回味。另外建立劇場時可以指定畫風（動漫或寫實），場景圖會照著畫。
4. 新增「怎麼玩」導覽：聊天頁上方多了一個入口，用九個章節總覽主要玩法，第一次進來也會有提示帶你認識它；創作區同樣補上了新手說明與導覽，每張功能卡都講清楚「能做什麼、怎麼開始、成果會去哪」。
5. 和角色見面時，同場模式現在是預設：進來就能看到彼此、也能直接按「讓她先開口」；切換角色時不再被強制跳回訊息模式，你選擇的模式會保留。
6. 修正手機上送出訊息後，輸入框卡在半個畫面高、明明是空的卻縮不回去的問題。
7. 修正 Firefox 上毛玻璃與遮罩效果整體失效的問題——聊天浮層、彈窗背景等處的模糊效果現在正常顯示了。
8. 角色不會再把你提到的現實事務（工作、約定、待辦）擅自改編成她的劇情，也不會替它補上不存在的公司名、人名或日期；她提起你的事情時，只會照你原本說過的講，第一次聊到她故事裡的事也會當作你還不知道來好好介紹。
