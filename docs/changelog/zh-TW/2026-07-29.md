# 2026.07.29 更新版本

1. 約定終於會「過去」了：你和角色約好的事，時間過了就自然翻篇。角色不會再反覆提起早已過期的邀約；隔天才答應的邀請也會正確算數。沒能成行的約定，角色會誠實記下「那次沒去成」收尾，而不是假裝完成或永遠惦記著。
2. 沒有一起做過的事，不會再被寫成「一起完成」：只有你真的參與過的活動，角色才會把你寫進回憶與動態，不會再憑空多出「我們的回憶」。
3. 角色的記憶會標上真實日期：過去寫進記憶的「明天」「下週」會隨時間變質（幾週後她還在「期待明天」）；現在記下來的都換算成具體日期，角色的時間感不再錯亂。
4. 長期目標會定期盤點：完成的收掉、過期的放下、相近的合併，不會累積一長串永遠掛著的目標；聊天時也只帶最相關的幾條，不再整串塞進對話。
5. 行程不再和真實天氣唱反調：角色排未來行程時不會再自行想像天氣；當天天況與原本排的明顯衝突時（例如突然下雨），行程中矛盾的段落會自動調整——已經發生的、和你約好的部分不會被改動。
6. 日常與劇情靈感大量擴充：隨附的生活小事與劇情素材新增兩百多條（含日系與西方地區風味），並保證兩個月內不重複；行程規劃也學會避免連續幾天排同類活動，延續性的活動會帶著新進展，角色的日子不再一成不變。
7. 角色不會再莫名複讀：同一則主動訊息同時送到多個聊天管道時，角色不會再把它誤認成新內容而重複講一次。
8. 登入不會再突然斷線：持續使用時登入狀態會自動延長，不會用到一半被計時器登出。
9. 穩定性與安全性修補：修正行程規劃在特定情況下的連續空轉重試、站台自訂設定在啟動時偶爾沒載入的問題，並更新了幾個含已知弱點的底層依賴。
