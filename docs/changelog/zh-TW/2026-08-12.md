# 2026.08.12 更新版本

1. 同一家供應商現在可以同時保留好幾組連線：如果你用的中轉／代理商發了多把 API key、每把能用的模型不一樣，以前後存的那組會無聲蓋掉前一組，設定看起來存進去了、實際上只有最後一組活著。現在第二組之後只要填一個「連線代號」，它就會成為模型選單裡看到的 id（例如 `custom_openai_compatible__relay-b`），每張連線卡片也會標出自己的 id。代號留空就維持原本的名稱，既有設定完全不受影響。對話模型、圖片、影片都適用；語音、向量與搜尋仍是一次只掛一個後端。
2. 角色說「晚點再跟你說」之後，真的會回來赴約：以前這類約定常常被她自己的主動訊息冷卻時間擋掉，時間到了卻一句話都沒有。現在約定會另外記下一個赴約時刻，到點即使還在冷卻中，她也會回來把話說完。
3. 回覆語言更穩定，修掉了偶爾冒出別種語言的情況；另外工具（搜尋、看圖、產圖等）該不該端到她面前，改成逐個工具判斷，不再一次整批塞給模型。
